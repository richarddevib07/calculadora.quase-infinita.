# INFINITECALC.quase-infinita.
♾️ Calculadora Infinita — Um projeto que nasceu da curiosidade pela matemática!

A ideia de desenvolver a Calculadora Infinita surgiu enquanto eu estudava matemática avançada. Durante meus estudos, comecei a pensar em como seria criar uma ferramenta capaz de realizar cálculos extremamente complexos, trabalhar com números gigantescos e explorar operações que vão muito além de uma calculadora convencional.

Foi assim que nasceu esse projeto!

Desenvolvida com HTML, CSS e JavaScript, a calculadora conta com recursos como potenciação, fatoriais, raízes, logaritmos, funções trigonométricas e precisão decimal configurável de até 1.000 dígitos.

Mais do que desenvolver uma calculadora, esse projeto foi uma oportunidade de transformar uma curiosidade matemática em uma aplicação prática, colocando meus conhecimentos de programação à prova e explorando novas possibilidades.
